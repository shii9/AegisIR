# Security Policy

AegisIR v0.2.0 is a learning and research prototype. It is not a supported enterprise incident response product. Any production use requires independent security review and a documented authorization/preservation policy.

Please report vulnerabilities responsibly to the repository maintainer without including customer data, sensitive host logs, malware samples, real SSH keys or live credentials in a public issue. See [Security Model](README.md#security-model) for known restrictions.
