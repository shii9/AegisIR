# Changelog

## v0.2.0 — Hybrid Go/Python local prototype

- Introduced Go CLI/numbered TUI, offline investigation help, 12 bounded Linux collectors and process-to-socket metadata.
- Added Python standard-library case engine with SQLite, explainable rules, six-phase checklist, findings, approvals, notes and timeline.
- Added SHA-256 evidence checks, local chained audit verification, report export and case closure validation.
- Added experimental guarded local response action types (lab-only and default disabled).
- Added 9 Python unit tests, Go unit tests, end-to-end smoke tests, documentation, CI example, amd64/arm64 release builds.

**Not included:** Production containment, remote agents, SIEM integration, signed evidence chain, memory acquisition, trusted host baselines, ML/LLM orchestration, independent recovery verification.
